# AI-Code-Revieweer# 🛡️ AI Code Reviewer & Security Auditor

A lightweight, powerful Streamlit app powered by Google's **Gemini 2.5 Flash** model to analyze code snippets for security vulnerabilities, logic bugs, performance bottlenecks, and code smells.

---

## ⚡ Features
- **Multi-language Support**: Python, JS/TS, C++, Java, Go, Rust, SQL, and more.
- **File Upload & Direct Input**: Upload code files or paste snippets directly.
- **Structured Audit Report**:
  - Code Quality Score (0–100)
  - Security Vulnerability scanning (OWASP, injection risks, etc.)
  - Refactored code snippet with fixes
- **Fast Execution**: Built with Streamlit and Gemini Flash for low-latency feedback.
